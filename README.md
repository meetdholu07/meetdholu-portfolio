# Meet Dholu Portfolio v2

Animated Next.js portfolio ready for Vercel.

Dependencies are intentionally minimal: Next.js, React and React DOM only. Animations use CSS, not an animation library.

Run:
npm install
npm run dev

Deploy:
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Vercel auto-detects Next.js.
4. Deploy and share the generated `*.vercel.app` URL.

Before publishing, replace the demo email, GitHub, LinkedIn, and Campus Connect URLs in `app/page.tsx`.

Never put passwords, private keys, JWT secrets, database credentials or other secrets in this portfolio.
